# The CIA Traid

## Overview

Understand the CIA Triad and how it shapes cyber security mindset.

## What I Learned

- CIA Triad

## Exercises

### Exercise 1 — [Understanding CIA Traid]

**Q1.** Which pillar of the CIA focuses on preventing unauthorized modification of data?
**Answer:** Integrity

**Q2.** Which pillar of the CIA focuses on preventing unauthorized access to data?
**Answer:** Confidentiality

**Q3.** Which CIA pillar ensures data is available to users when needed?
**Answer:** Availabilty

**Q4.** Which CIA pillar gets impacted if the data becomes untrustworthy?
**Answer:** Integrity

**Q5.** What is the term used collectively for all these pillars?
**Answer:** CIA Triad

### Exercise 2 — [The Security Mindset]

**Q1.** CIA Triad is not just a set of definitions; it's a mindset. What type of mindset is it?
**Answer:** Security Mindset

## Key Takeaways

Key Terminology

    Confidentiality:
    Ensuring digital information is not available to unauthorized individuals.
    Integrity:
    Ensuring digital information is not modified without permission.
    Availability:
    Ensuring digital information is not unavailable when needed.


## Notes

The CIA Traid: Confidentiality, Integrity, Availability together these three principles explains what cybersecurity acutally protects.
Confidentiality: The Data should be only available to authorised users
Integrity: The data should not be modified without permissions
Availability: The data should be available when required

CIA Triad is not just a definition its a Security Mindset.
