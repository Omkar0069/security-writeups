# Windows Cli Basics

## Overview

This room explains basics of Windows CLI.

## What I Learned

cd - Used to display the full path like 'pwd' in linux, it is also used to change directory.
dir - List the content of the current directory. 'dir /a' to list all the hidden file.
cd <foldername> - To move to specific folder. 'cd ..' to move 1 level up.
dir /s <filename> - s Stand for search, it searches the file from the current directory to all sub folders.
type - Used to open file in terminal like 'cat'.
whoami - Which user account you are using.
hostname - Name of the computer.
systeminfo - What version of the windows is this?
ipconfig - Basic network info.
